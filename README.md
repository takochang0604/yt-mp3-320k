# 🎵 YT → MP3 | 高音質 320kbps 下載器

將 YouTube 影片轉換為 **320kbps 高音質 MP3** 並下載。

---

## 🚀 使用方式

### 1. 下載專案
點擊右上角 **Code → Download ZIP**，解壓縮到任意位置。

### 2. 雙擊 `start.bat` 啟動
首次執行會自動安裝所有必要工具（Node.js、yt-dlp、ffmpeg），全程無需手動操作。

### 3. 貼上 YouTube 網址，點擊下載
瀏覽器會自動開啟，貼上網址 → 點擊「轉換並下載 MP3」→ 完成！

---

## 💡 小提示

- 首次啟動會下載 yt-dlp 和 ffmpeg，請耐心等候
- 之後再次啟動只需幾秒鐘
- 關閉黑色命令視窗即可停止伺服器
- 僅供個人學習使用，請尊重版權

---

## ⚠️ 環境需求

- Windows 作業系統
- 網路連線（首次需下載工具）
- Node.js（`start.bat` 會自動安裝）
